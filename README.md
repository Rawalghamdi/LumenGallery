# Lumen Gallery

Contemporary art exhibition site built with React + Vite + Tailwind CSS.

## Features

- Browse 12 seminal artworks with artist portraits
- Filter by art movement / style
- Debounced search by title, artist, origin or style
- Gallery Dashboard with stats, style breakdown and origin breakdown
- Fully light-mode, no external API keys required

## Getting started

```bash
npm install
npm run dev
```

## Stack

- React 18
- Vite 6
- Tailwind CSS v4
- react-use (debounce)
